FamiCraft is an SMB1r resource pack that makes mario more like minecrarft


rules for FamiCraft if you want to contribute

1. tiles should be 3 colors! (although you may have a palette fit with 8x8 instead of  16x16)
2. sprites (players, enemies, and npcs) can use at most 6 colors (but use as little colors as possible within reason)
3. use programmer art as main reference (but theres exceptions if you think it would look better with the new textures as ref (or if theres no programmer art for it))
4. try to make the replacement minecraft block or item a mechanical parallel to the mario block (if theres none, try having a redstone component or pick the next best thing)
5. you can use cut items (ruby or gear) and items in snapshots (ice balls or brittle ice)
6. april fools features should be a last resort, never use them if theres a vanilla feature that is similar
7. no modded or addon items
8. you can bend the rules, just ask if its ok
